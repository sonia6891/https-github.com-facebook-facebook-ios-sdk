# v112: 首次使用與資料權限

本次採用核准的灰色厭世貓主視覺、奶油底與暖杏色「先使用，不登入」按鈕。

## 已實作的分類

- 不登入：本機工作資料自動保存、手動備份與匯入，不開啟雲端同步。
- 免費帳號：登入只辨識帳號與訂閱；本機工作區按帳號隔離。訪客資料帶入帳號需要確認。
- 有效 Pro／試用：後端確認資格且使用者啟用後，才上傳、讀取與即時同步工作資料。
- 到期：停止同步，保留本機資料。取消下期續訂不提前結束已付款期間。
- 舊版已存雲端資料：遷移時保留唯讀封存，原帳號可明確操作取回，不作免費同步通道。
- 淺色／深色：裝置偏好優先，不被雲端舊資料覆蓋。

## 驗證範圍

2026-09-23：15 項既有主題回歸檢查、25 項瀏覽器介面／帳號流程檢查通過。瀏覽器中的身分與方案回應使用測試替身，不涉及真實帳號授權或扣款。

Supabase 生效後，以兩個暫時測試身分在交易內切換 authenticated／anon 角色，23 項權限檢查通過；測試資料整筆交易回滾。包含免費直接資料庫存取限制、本人資料隔離、有效 Pro 與試用、到期／無限或空到期日拒絕、取消續訂仍在有效期、舊備份唯讀、錯誤版本拒絕覆寫、自行提升方案禁止。

正式部署另比對 index.html、sw.js、核准主視覺的 SHA-256；結果存於 GitHub Actions release verification artifact。部署工作流保持 contents: read，不授予網站部署流程寫入程式碼的權限。
